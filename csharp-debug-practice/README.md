# C# デバッグ実行 復習教材

Visual Studio のデバッグ機能を使いこなすための練習教材です。

## 📚 教材構成

1. **debug-cheatsheet.md** - Visual Studio デバッグ機能チートシート
2. **Sample1_BasicDebug.cs** - 基本的なデバッグ練習
3. **Sample2_FindBugs.cs** - バグ探し練習
4. **Sample3_Advanced.cs** - 応用練習

## 🎯 学習目標

- [ ] ブレークポイントの設定・解除ができる
- [ ] ステップ実行（F10, F11）を使いこなせる
- [ ] ローカルウィンドウで変数の中身を確認できる
- [ ] ウォッチ式を使って特定の変数を追跡できる
- [ ] デバッグ実行でバグの原因を特定できる

## 🚀 使い方

### 1. Visual Studio でプロジェクトを作成

```bash
# コンソールアプリケーション (.NET 6.0 以上)
dotnet new console -n DebugPractice
cd DebugPractice
```

### 2. サンプルコードをコピー

各 `.cs` ファイルの内容を `Program.cs` にコピーして実行

### 3. デバッグ実行で練習

1. 左側をクリックしてブレークポイントを設定
2. F5 でデバッグ実行開始
3. F10 でステップ実行
4. ローカルウィンドウで変数を確認

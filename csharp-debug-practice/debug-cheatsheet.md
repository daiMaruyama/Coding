# Visual Studio デバッグ機能 チートシート

## ⌨️ キーボードショートカット

| キー | 機能 | 説明 |
|------|------|------|
| **F5** | デバッグ実行開始 | ブレークポイントまで実行 |
| **Shift + F5** | デバッグ停止 | デバッグを終了 |
| **Ctrl + Shift + F5** | 再起動 | デバッグを最初からやり直す |
| **F9** | ブレークポイント設定/解除 | カーソル行にブレークポイントを設定 |
| **Ctrl + Shift + F9** | 全ブレークポイント削除 | すべてのブレークポイントをクリア |
| **F10** | ステップオーバー | 次の行へ進む（関数は実行するが中に入らない） |
| **F11** | ステップイン | 次の行へ進む（関数の中に入る） |
| **Shift + F11** | ステップアウト | 現在の関数から抜ける |

## 🪟 ウィンドウ

### ローカル（自動表示）
- 現在のスコープ内の変数をすべて表示
- 変数の型と値が確認できる

### ウォッチ
- 追跡したい変数や式を登録
- デバッグ中に常に値を監視

### 呼び出し履歴（コールスタック）
- 現在の関数がどこから呼ばれたか確認
- 関数呼び出しの流れを追跡

### イミディエイト
- デバッグ中にコードを実行できる
- 変数の値を変更したりメソッドを呼び出したりできる

## 💡 便利テクニック

### 1. 条件付きブレークポイント
ブレークポイントを右クリック → 条件
```csharp
例: i == 5  // i が 5 の時だけ停止
例: name == "test"  // name が "test" の時だけ停止
```

### 2. ヒットカウント
ブレークポイントを右クリック → ヒット カウント
```
例: 10回目のループで停止
```

### 3. 変数にマウスオーバー
デバッグ中に変数にマウスを当てると値が表示される

### 4. データヒント（ピン留め）
マウスオーバー時に📌アイコンをクリックで固定表示

### 5. クイックウォッチ
変数を選択して **Shift + F9** で詳細確認

## 🎯 デバッグの基本フロー

```
1. 怪しい箇所にブレークポイントを設定
   ↓
2. F5 でデバッグ実行
   ↓
3. ブレークポイントで停止
   ↓
4. ローカルウィンドウで変数確認
   ↓
5. F10 でステップ実行しながら動作確認
   ↓
6. バグの原因を特定
   ↓
7. コード修正
   ↓
8. Ctrl + Shift + F5 で再実行して検証
```

## 🐛 よくあるバグパターン

### 配列の範囲外アクセス
```csharp
int[] arr = new int[5];
arr[5] = 10;  // ❌ IndexOutOfRangeException
```
→ ブレークポイントで配列のインデックスを確認

### Null参照
```csharp
string str = null;
int len = str.Length;  // ❌ NullReferenceException
```
→ ブレークポイントで変数がnullかどうか確認

### ループの無限ループ
```csharp
for (int i = 0; i < 10; i--)  // ❌ i-- で減ってしまう
```
→ ブレークポイント + ウォッチで i の値を追跡

### 型変換エラー
```csharp
string input = "abc";
int num = int.Parse(input);  // ❌ FormatException
```
→ ブレークポイントで input の値を確認

## 📝 実践Tips

- **まずは怪しい箇所の前後にブレークポイント**を張る
- **ローカルウィンドウ**で全変数を確認
- **ステップ実行（F10）**で一行ずつ動作を確認
- **ウォッチ**に重要な変数を登録して常に監視
- **条件付きブレークポイント**で特定の条件だけ停止
